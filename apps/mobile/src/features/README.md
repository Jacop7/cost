# features/ — 화면 ID ↔ 기능 모듈 매핑

탭별 feature 모듈. 각 모듈은 `screens/`(화면) · `demoData.ts`(임시 데이터)로 구성하고, 추후 `hooks/`(쿼리·뮤테이션)을 더한다.
공통 UI 킷은 `src/components/kit`, 계산은 `@sikjae/core`, 데이터 계약은 `@sikjae/types`.

하단 탭 순서: **식재료(ING) · 레시피(RCP) · 발주(ORD) · MY**.
