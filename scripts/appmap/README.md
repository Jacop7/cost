# 현재 Expo 탭 탐색기

사용자 요청: 기존 Expo는 보존하고 `/appmap/`에 프로토타입과 같은 순서의 탭만 붙인다.
화면·토큰·DB 로직을 복제하지 않는다. 후속 사용자 승인으로 기존 Web Alert 표시만
공용 Sheet 호스트로 보완했다. 이 보완은 기본 Expo Web에도 적용되며 네이티브 Alert는 그대로다.

실행: 저장소 루트에서 `node scripts/appmap/start.mjs`.
8091/8094 포트가 비어 있어야 한다. 8091은 로컬 프록시, 8094는 같은 작업 폴더의 Expo Metro다.
`http://localhost:8091/`은 기존 Expo, `/appmap/`은 그 화면을 iframe으로 여는 탐색기다.
앱 소스를 수정하면 같은 Metro의 양쪽 화면에 반영된다. **실제 로컬 데이터 모드**에서 앱 안에서 저장하면 같은 로컬 DB에 저장된다.
기본 선택인 **샘플 미리보기 모드**에서는 아래 설명처럼 데이터 응답 일부를 바꾸며 저장·삭제를 차단한다.
별도 화면 사본이나 동기화 작업은 없다. 개발용이며 production bundle에서 import하지 않는다.

탭은 정본 HTML의 domains/screens/popupTabs/ingredientEditScreens/parentScreens **리터럴**에서 추출한다.
실행 가능한 프로토타입 코드는 평가하지 않는다. 현재 audit의 185 target 집합과 차집합이 있으면 실패한다.
숨김 3개는 기본 탭을 바꾸지 않고 전체 목록에 따로 노출한다. 연결 정보는 기존 surface registry에서 가져온다.

상세 화면의 ID는 실제 앱의 목록 응답에서 id/name만 관찰하여 선택한다. 인증/저장소 값을 읽지 않는다.
기본 앱에는 observer를 넣지 않으며 iframe 요청의 `__appmap=1`에서만 주입한다.
실제 데이터 모드는 코드에 열거된 기존 열기 버튼/탭만 클릭한다. 저장·삭제 확정은 자동 실행하지 않는다.
샘플 모드의 제한된 상태/결과 시나리오는 아래 R2 계약에 따라 DB 전송 없이 기존 UI를 재현한다.
직통 어댑터가 없는 팝업은 **진입 화면만 표시**하고 경고한다. 185개 목록 포함은 185개 자동 연결 완료나
디자인 일치·P3/P4 종결을 뜻하지 않는다. 데이터가 없는 상세 상태를 가짜 화면으로 대체하지 않는다.

시험: `node --test scripts/appmap/model.test.mjs`.

## 샘플 미리보기 + 모든 탭 제약 안내 (사용자 추가 결정)

사용자가 샘플 데이터와 제약 안내를 허용했다. 제품 UI를 새로 만들거나 DB에 임의 매출·재고를
저장하는 대신 **기존 Expo가 받는 일부 조회 응답**만 개발 iframe 안에서 샘플로 대체한다.
`samples.js`는 화면/스타일 코드가 아닌 RPC 응답 모양의 예시 데이터다. 기본 Expo `/`는 무변경이다.

- `/appmap/` 기본 모드는 샘플. `?data=real` 또는 데이터 선택으로 실제 로컬 모드로 바꾼다.
- 파란 안내에 샘플 응답 적용 건수를 표시한다. **나머지 값은 실제 로컬 조회값**이므로 완전히
  독립된 가짜 DB라고 주장하지 않는다. 샘플 금액은 계산 정확성·원장 검증 근거가 아니다.
- 옵션 있음/없음, 옵션 편집/더보기, 손익 이력, 영업 상태/종료 확인, 매출·재료·부자재·고정지출
  상세를 샘플로 열 수 있다. 옵션 있음/없음은 기존 Expo DOM 상태까지 확인한다.
- 없는 팝업·네이티브 Alert·저장 결과 상태와 기존 서버 계약 오류는 **노란 제약 안내 카드**로 표시한다.
  아래 실제 진입 화면도 유지한다. 제약 안내를 제품 팝업 구현 완료로 집계하지 않는다.
- 원본 탭 185개(62 화면 + 123 팝업/상태), 숨김 포함 순서와 계층은 변하지 않았다.
- 샘플 모드의 저장/삭제/미등록 RPC는 fetch guard가 차단한다. 외부 bridge 로드 전 inline
  bootstrap부터 fail-closed다. 샘플 또는 bridge 로딩 실패 시 iframe을 중단하고 안내한다.
- 타깃·run별 샘플 적용 receipt를 대조한다. 필요한 receipt가 없으면 샘플 완료를 표시하지 않는다.
- 샘플 guard/receipt 검수 Finding을 반영하고 내부 Sol 재검수에서 추가 blocker 없음.
  구조·샘플 단위 시험 **16/16**, 실제 브라우저 음성/모드 시험 **4/4**.
