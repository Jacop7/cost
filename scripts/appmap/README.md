# 현재 Expo 탭 탐색기

사용자 요청: 기존 Expo는 보존하고 `/appmap/`에 프로토타입과 같은 순서의 탭만 붙인다.
화면·컴포넌트·토큰·provider·DB 로직을 복제하거나 변경하지 않는다.

실행: 저장소 루트에서 `node scripts/appmap/start.mjs`.
8091/8094 포트가 비어 있어야 한다. 8091은 로컬 프록시, 8094는 같은 작업 폴더의 Expo Metro다.
`http://localhost:8091/`은 기존 Expo, `/appmap/`은 그 화면을 iframe으로 여는 탐색기다.
앱 소스를 수정하면 같은 Metro의 양쪽 화면에 반영된다. 앱 안에서 저장하면 같은 로컬 DB에 저장된다.
별도 화면 사본이나 동기화 작업은 없다. 개발용이며 production bundle에서 import하지 않는다.

탭은 정본 HTML의 domains/screens/popupTabs/ingredientEditScreens/parentScreens **리터럴**에서 추출한다.
실행 가능한 프로토타입 코드는 평가하지 않는다. 현재 audit의 185 target 집합과 차집합이 있으면 실패한다.
숨김 3개는 기본 탭을 바꾸지 않고 전체 목록에 따로 노출한다. 연결 정보는 기존 surface registry에서 가져온다.

상세 화면의 ID는 실제 앱의 목록 응답에서 id/name만 관찰하여 선택한다. 인증/저장소 값을 읽지 않는다.
기본 앱에는 observer를 넣지 않으며 iframe 요청의 `__appmap=1`에서만 주입한다.
자동화는 코드에 열거된 기존 열기 버튼/탭만 클릭한다. 저장·삭제·결제·확정은 자동 실행하지 않는다.
직통 어댑터가 없는 팝업은 **진입 화면만 표시**하고 경고한다. 185개 목록 포함은 185개 자동 연결 완료나
디자인 일치·P3/P4 종결을 뜻하지 않는다. 데이터가 없는 상세 상태를 가짜 화면으로 대체하지 않는다.

시험: `node --test scripts/appmap/model.test.mjs`.
