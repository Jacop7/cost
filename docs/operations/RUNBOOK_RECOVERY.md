# 복구 실행 진입점

복구·백업·PITR·RPO/RTO 정책은 [브랜치·DB 운영 기획안](../브랜치-DB-운영-기획안.md)과
[서버 확장 아키텍처](../서버-확장-아키텍처-기획안.md)가 소유한다.

1. 대상 환경·exact SHA·장애 시점·영향 범위를 고정한다.
2. 백업 파일, PITR 가능 범위, forward fix와 rollback 후보의 증거를 확인한다.
3. 스테이징 또는 격리 환경에서 복원 검증을 먼저 수행한다.
4. 운영 복구는 `05 운영 배포 · 복구 게이트`의 사람 Decision 뒤에만 수행한다.
5. 전후 검산·누락·재발 위험 pointer를 [릴리스 게이트](../team/RELEASE_GATE.md)에 연결한다.

이 문서는 복구 명령·자격증명·현재 백업 상태를 보관하지 않는다.
