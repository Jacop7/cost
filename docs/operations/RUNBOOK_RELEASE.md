# 릴리스 실행 진입점

브랜치·CI·DB 배포·운영 승인 정책은 [브랜치·DB 운영 기획안](../브랜치-DB-운영-기획안.md)이
소유한다. 이 문서는 각 릴리스에서 확인할 링크 순서만 제공한다.

1. [작업큐](../작업큐.md)에서 승인 대상 Task와 exact SHA를 확인한다.
2. [릴리스 게이트 장부](../team/RELEASE_GATE.md)에서 보호 CI·스테이징·백업·사람 Decision pointer를 확인한다.
3. 적용 환경과 migration 목록은 기존 `docs/deployments/` 증거에서 확인한다.
4. 운영 적용은 `05 운영 배포 · 복구 게이트`에서 사람의 명시적 Go가 있을 때만 실행한다.
5. 결과 pointer를 릴리스 장부와 모든 팀 상황실에 연결한다.

현재 릴리스 상태나 환경 자격증명은 이 파일에 기록하지 않는다.
