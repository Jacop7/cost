# 고객지원 진입점

오픈 초기 고객지원은 사람이 소유하고 AI는 분류·답변 초안·증거 연결만 보조한다.

1. 개인정보·비밀을 제외한 재현 조건과 사용자 영향을 기록한다.
2. 사용법 문의, 제품 결함, 데이터 정정, 보안·운영 사고를 분리한다.
3. 결함은 [작업큐](../작업큐.md)의 새 Task로, 사고는 [사고 대응](./RUNBOOK_INCIDENT.md)으로 연결한다.
4. 답변은 확정 제품 동작과 실제 증거만 사용하고 추정 복구 시각을 약속하지 않는다.
5. 반복 교훈은 바로 정책화하지 않고 [TEAM_LEARNING](../team/TEAM_LEARNING.md)의 승격 절차를 따른다.

고객 대화 원문과 개인정보는 저장소에 복사하지 않는다.
