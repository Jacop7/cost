3. MVP 범위 정의
1차 MVP의 기준: ‘수기 입력만으로 재고·원가·발주·손익의 한 사이클이 완결되는가’. 자동화(OCR·링크 추출·그래프·알림)는 사이클이 돌아간 뒤에 얹는다.
1차 MVP가 제공하는 핵심 가치
식재료를 등록하고 → 재고를 개수로 세고 → 부족하면 후보로 모아 주문을 기록하고 → 입고로 단가가 쌓이고 → 레시피 손익(고정 지출 포함)이 자동 계산된다.

1차 단위 범위: 미터법만(g·kg·ml·L·개). 단위 시스템 전환·컵/스푼은 2차.
1차 제외 원칙: 사진/OCR·외부 페이지 파싱·그래프·푸시 등 ‘인프라성 기능’은 전부 2차 — 1차는 입력과 계산의 정확성에 집중.
데이터 모델은 1차부터 2.1 ERD 전체를 그대로 구현(파생 테이블 포함) — 2차 기능이 스키마 변경 없이 얹히도록.
4. 다음 단계
화면 흐름도(네비게이션 맵)와 디자인 시스템(색·뱃지·카드 규칙: 비용 그레이·이익 초록 등) 정리.
1차 MVP 백로그를 화면 단위 태스크로 분해 → 개발 착수.
