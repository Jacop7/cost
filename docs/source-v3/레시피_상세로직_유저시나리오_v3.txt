0. 설계 원칙 — 레시피는 ‘메뉴 1개의 손익계산서’
레시피 페이지는 조리법 책이 아니라 ‘이 메뉴 하나 팔면 실제로 얼마가 남는가’를 답하는 손익 화면이다. 조리 과정·사진은 다루지 않고(원가 전용) 재료·양·비용만 다룬다. 정확히 계산되는 것(재료 원가·추가 지출)은 1인분 단위로, 1인분 배부가 애매한 것(인건비·광고 등)은 월 단위 ‘고정 지출’로 모아 메뉴별 평균 판매량 기준으로 1개 원가에 배분한다 — 그래서 모든 숫자가 검증 가능하다.
핵심 계산 사슬 (1인분 기준)
순이익 = 판매가 − 세금 − 재료 원가 − 고정 지출(평균 판매량 기준 배분) − 추가 지출(정액)
재료 원가 = 식재료 페이지의 ‘기준 단가(가중평균 + 로스 반영)’ 자동 연동
고정지출률 = 월 고정 지출 합계 ÷ 총 월매출 — 마이페이지에서 매월 갱신. 레시피별 1개 고정비는 각 메뉴 평균 판매량으로 배분(3.3), 전 레시피 자동 반영
입력은 N인분으로 편하게, 저장·계산은 1인분으로 표준화(대원칙)
 | 
1. 역할과 데이터 흐름상 위치
[① 식재료]  기준 단가·로스율·단위  ──▶  [② 레시피]  1인분 원가·순이익
[마이페이지] 고정 지출(월) → 고정지출률  ──▶  [② 레시피]  평균 판매량 기준 배분 차감
재료비·판매가·고정지출 변경  ──▶  순이익률 변동 추이에 변경일 점 기록
[② 레시피] 1인분 소요량  ──▶  [발주 현황] 레시피 기준 발주(향후)
 | 

식재료 단가나 고정지출률이 바뀌면 모든 레시피의 순이익이 자동 재계산되고, 목표 순이익률 미달 시 경고가 켜진다. 변경은 전부 ‘순이익률 변동 추이’에 점으로 남아 원인 추적이 가능하다.

고정지출률과 1,000원당 표시
고정지출률 = 월 고정 지출 합계 ÷ 총 월매출   (예: 8,930,000 ÷ 28,500,000 = 31.3%)
직관 표시: ‘매출 1,000원당 313원’ — 어떤 판매가에도 바로 곱해 볼 수 있다.
매월 갱신하면 전 레시피에 자동 반영(변경일에 추이 점 기록). 재료비는 입고 데이터에서 자동 합산되어 월 손익 리포트(매출 − 고정 지출 − 재료비)까지 산출.

반제품(중간 레시피) — 1차 범위 제외, 구조만 예약
탕수육 소스처럼 ‘레시피를 재료로 쓰는’ 중첩은 1차에서 지원하지 않는다(소스는 식재료로 등록해 해결).
재료 라인의 참조 타입을 ‘식재료|레시피’로 설계해 두어, 향후 1단계 중첩을 열 수 있게 한다.

3. 핵심 계산 로직
3.1 N인분 → 1인분 환산
공식
1인분 소요량 = 입력 소요량 ÷ 기준 인분(N)   예) 10인분 2,000g → 1인분 200g
 | 
3.2 재료 원가
공식
1인분 재료 원가 = Σ ( 1인분 소요량 × 식재료 기준 단가 )
기준 단가 = 구매이력 가중평균 × 로스 반영(① 4.1·8.6) — 자동 갱신.
 | 
3.3 고정 지출 차감
이번 버전부터 고정 지출은 ‘판매가 × 률’ 대신 메뉴별 평균 판매량을 기준으로 배분한다. 레시피마다 월 평균 판매량(집계 기간: 하루/일주일/한 달 → 월 환산)을 입력하면, 전체 판매 대비 이 메뉴의 판매 비중만큼 월 고정 지출이 배분되고, 그 금액을 판매량으로 나눠 1개당 고정비가 나온다. 많이 팔수록 1개가 떠안는 고정비가 줄어 순이익률이 올라간다.
공식
1개당 고정 지출 = 이 메뉴 배분 고정비 ÷ 월 평균 판매량
배분 고정비 = 월 고정 지출 합계 × 이 메뉴 판매 비중(전체 판매 대비). 항목별(인건비·수수료·포장·배달·광고)로도 1개 환산값을 함께 표시. 검산: 제육 300개/월·전체의 12% → 1개당 3,760원(판매가의 31.3%).
 | 
3.4 추가 지출 차감
공식
1인분 추가 지출 = Σ 지출명별 정액 금액
 | 
3.5 세금(부가세) 자동 계산
부가세(포함/별도/면세 토글)는 기본 세금 항목이며, 카드 수수료·기타 세금 등 ‘세금 항목’을 판매가 대비 %로 직접 추가할 수 있다. 모든 세금 항목을 합산해 손익표의 ‘(−) 세금’ 행으로 차감한다.
설정
 | 계산
 | 설명
 | 
포함(기본)
 | 부가세 = 판매가 × 10/110
 | 판매가가 부가세 포함 소비자가일 때. 예: 12,000원 → 1,091원.
 | 
별도
 | 부가세 = 0 차감
 | 판매가가 공급가일 때.
 | 
면세
 | 부가세 = 0
 | 면세 사업자.
 | 
단순화 주석: 실제 납부세액은 매출세액 − 매입세액이지만, 메뉴 손익에서는 보수적으로 매출분 부가세만 차감한다.
3.6 순이익 · 권장 판매가
공식
순이익 = 판매가 − 세금 − 재료 원가 − 고정 지출 − 추가 지출
순이익률(%) = 순이익 ÷ 판매가 × 100   /   재료 원가율(%) = 재료 원가 ÷ 판매가 × 100
권장 판매가(목표 달성 최소가) = (재료 원가 + 추가 지출) ÷ (1 − 1/11 − 고정지출률 − 목표율)  [부가세 포함 시]
 | 
기본 단위는 1인분(개당) 원화. 무게 판매 품목(정육·베이커리)은 100g당 표시 옵션. 손익표의 모든 행은 ‘금액 + 판매가 대비 %’ 두 칸으로 표시한다.

3.8 순이익률 변동 추이 (스냅샷)
기간별 조회: 추이는 1·3·6·12개월 기간으로 볼 수 있고, 순이익률과 함께 ‘재료 원가율’ 라인을 같이 표시한다 — 재료 단가가 오르면 재료 원가율이 올라가고 순이익률이 내려가는 관계를 한눈에 본다.
점이 찍히는 조건: ① 재료비(식재료 단가 갱신) ② 레시피 수정(판매가·재료·추가 지출) ③ 고정지출(월 갱신) — 셋 중 하나라도 바뀌면 그 변경 년월일로 순이익률 스냅샷 기록.
같은 날 중복 변경은 그날 최종값으로 점 1개. 신규 등록 시 저장일이 첫 점.
점 색상 = 원인: 재료비(주황) · 레시피 수정(파랑) · 고정지출(회색). 목표선(점선)과 함께 표시.
점 탭 → 변경 이력: ‘6/04 돼지고기 11.0→13.0원/g, 38.3→35.9%’처럼 내용·전후값 표시.
3.9 변동 연동 · 경고
식재료 단가·고정지출률 변경 시 전 레시피 자동 재계산. 목표 미달 전환 시 ▼경고(+선택 푸시).
판매가 시뮬레이션: 판매가를 임시로 바꿔 순이익 변화 미리보기, 권장 판매가(3.6 공식) 자동 제시.

4. 화면 구성
4.1 레시피 리스트
상단 요약: 메뉴 수 · 목표 미달 수 · 평균 순이익률.
카드: 메뉴명 + 판매가·재료 원가율 + 순이익(원·%) + 상태 색띠/뱃지(정상·▼목표 미달). 미달 카드엔 권장가 힌트.
정렬 기본 ‘순이익률 낮은순’(돈 안 되는 메뉴가 위로) · 검색 · 판매 상태 필터(중지 메뉴 흐리게).
4.2 레시피 상세
도넛 차트: 판매가 구성을 원형으로 — 순이익만 초록, 비용(고정·재료·세금·추가)은 그레이 계열 진하기(클수록 진함). 중앙에 순이익률. 레전드는 ‘남는 돈/나가는 돈’ 두 그룹.
손익표: 판매가(100%) → (−)세금·재료·고정·추가 → 순이익. 모든 행 ‘금액+%’ 표시, 미달 시 ▼ + 권장가.
재료 표(1인분 환산·단가·원가) + 최대 기여 재료 힌트(‘돼지고기가 재료 원가의 78%’).
고정 지출: 추가 화면과 동일한 항목별 표(원·%) + [자세히 보기] 바텀시트(월 실제 내역 + 1인분 환산 + 마이페이지 수정 링크).
추가 지출 표 → 순이익률 변동 추이(원인 색 점 + 변경 이력) → 판매가 시뮬레이션 버튼.
4.3 레시피 추가/수정
메뉴명 · 기준 인분(N) 선택.
재료: 식재료 검색 → 체크 후 사용량 입력 → [담기]로 장바구니에 모아 한 번에 추가(‘선택 N · N개 재료 담기’), N인분 기준 양 입력(컵/스푼 자동 환산) → 라인별 1인분 원가 즉시 표시. 직접 입력 금지(검색만). 사용량 입력 시트는 ‘이 메뉴 N개(기준 인분) 기준’으로 입력하며 라인 원가를 즉시 표시한다. 사용량 입력 시트는 ‘이 메뉴 N개(기준 인분) 기준’으로 입력하며 라인 원가를 즉시 표시한다.
판매가 · 부가세 토글 · 목표 순이익률 입력.
고정 지출 카드(자동·읽기전용): 항목별 판매가 대비 원·% 표 + 자세히 보기 시트.
월 평균 판매량 입력: 집계 기간(하루/일주일/한 달)으로 평균 수량을 넣으면 월 판매량으로 환산되고, 이 값으로 고정 지출이 메뉴별 배분된다(전용 화면 ‘평균 판매량’에서 입력·수정).
고정 지출 카드 표시: [1개 / 월 평균] 토글로 1개당·월 합계를 전환해 보고, ‘판매량(월 N개)’ 행과 항목별 원·%를 함께 보여준다. 자세히 보기 시트는 ‘월 실제 → 1개 환산’으로 항목 내역을 펼친다.
추가 지출: 지출명 + 금액 행 추가(이중계산 방지 안내).
손익 미리보기(입력과 동시 실시간) → 순이익률 변동 추이 → [저장](저장 시 오늘 날짜 점 기록).
4.4 고정 지출 입력 (마이페이지)
월 선택 → 총 월매출 입력 → 항목별 카드(총액/상세 토글): 인건비·플랫폼 수수료·포장비·배달/배송·광고/홍보비.
하단 요약: 고정 지출 합계(매출 대비 %) · 매출 1,000원당 고정지출 · 재료비(자동) · 월 순이익 추정.
저장 시 고정지출률 갱신 → 전 레시피 자동 재계산 + 추이 점 기록.
5. 유저 시나리오
시나리오 A — 레시피 등록 (대용량 기준 입력)
상황: 평소 10인분씩 조리하는 제육볶음을 등록한다.
동작: 레시피 → [+] → ‘제육볶음’, 기준 인분 10 → 재료 5종을 10인분 기준으로 입력(시스템이 ÷10 환산).
동작: 판매가 12,000원(포함) · 목표 40% · 월 평균 판매량 300개 입력 → 고정 지출 카드가 자동으로 3,760원(31.3%, 전체 판매의 12% 배분) 표시.
동작: 추가 지출 ‘특수 포장용기 300원’ 추가.
결과: 손익 미리보기 순이익 4,014원(33.4%) ▼목표 + 권장가 16,000원 → 가격을 고민한 뒤 저장(첫 추이 점 기록).
시나리오 B — 재료 단가 상승
상황: 돼지고기 입고가가 11.0 → 13.0원/g으로 상승(① 페이지 입고).
처리: 재료 원가 2,835 → 3,235원, 순이익률 자동 재계산. 추이에 주황 점 기록.
결과: 리스트 정렬과 ▼경고로 즉시 노출 → 시뮬레이션으로 판매가 조정 검토.
시나리오 C — 고정 지출 월 갱신
상황: 6월 1일, 5월분 고정 지출을 마이페이지에서 입력(인건비·수수료·포장·배달·광고).
처리: 고정지출률 30.1 → 31.3%로 갱신 → 전 레시피 순이익 자동 재계산, 각 레시피 추이에 회색 점.
결과: 월 손익 요약(매출 − 고정 − 재료비 = 11,370,000원·39.9%)도 함께 산출.
시나리오 D — 저마진 메뉴 정리
동작: 리스트 ‘순이익률 낮은순’ → 된장찌개 23.4%, 제육볶음 33.4%가 상단에.
동작: 상세 도넛에서 비용 구조 확인 → 권장가/재료 변경/단종 판단.
결과: 감으로 하던 메뉴 정리를 숫자로 결정.
시나리오 E — 컵·스푼으로 양 입력
동작: ‘고추장 3큰스푼’ 입력 → 45ml 자동 환산(① 4.8).
결과: 머릿속 단위 그대로 입력해도 원가는 ml 기준으로 정확히 계산.

7. 발주 연동(향후)과 다음 단계
레시피 기준 발주(① 8.1): ‘내일 제육 50인분’ → 1인분 소요량 × 50 → 식재료 필요량 합산 → 잔여 차감 → 발주 후보.
발주 현황 페이지: 식재료 기준(확정) + 레시피 기준(본 문서 확정 후) 두 탭.
마이페이지(④ 문서): 고정 지출(월) 입력·이력, 목표 순이익률 기본값, 카테고리·단위 시스템·구매처 관리, 알림, 월 손익 리포트. (세금/부가세는 레시피별 토글·항목 추가로만 관리 — 마이페이지에 없음.)
