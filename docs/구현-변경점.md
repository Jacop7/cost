## 2. 재고 상태 (식재료)

| v3 스펙 | 구현 |
|---|---|
| 충분 / 부족 / 소진임박 (3단계) | **여유 / 소진 임박 (2단계)** — '부족'은 **'소진 임박'으로** 흡수 |

- 식재료 리스트 카드의 상태 뱃지는 여유(초록)/소진 임박(빨강) 2단계.
- ⚠ 처음에는 '부족'을 **'여유'로** 흡수했는데, 그러면 안전재고 미달인데 '여유'라고
  쓰게 된다(실측 7종. 애호박은 안전선 1,500g 에 재고 720g 인데 '여유 ⚠' 였다).
  안전재고란 "이 밑으로 내려가면 발주해야 하는 선"이므로 그 아래는 소진 임박이 맞다.
  흡수 방향을 뒤집었고, 배지가 말하므로 별도 ⚠ 아이콘은 없앴다 —
  같은 사실을 두 기호로 말하지 않는다.
- 발주 후보는 사유 뱃지(안전재고 미달 · 곧 소진) 별도 유지.

## 3. 단위 · 표기 규칙

- **화면 노출 단위는 kg · g · ml + 개수(개/모) 만.** 망 · 통 · 팩 · 박스 · 판 등 구매단위 라벨은 표기에서 제거하고 상품명/거래처로 분리.
  - 예: `양파 1망(1.2kg)` → `양파 · 1.2kg`, `앞다리살 5kg 냉장` → 상품명 `앞다리살 냉장` · 용량 `5kg`.
- **구매 옵션 표기 형식**: `식재료명 · 용량 · 금액` / `구매처 · 단가(원/g)`.
- **단가 미리보기(ING-03/05)**: 구매가 단가 + 실사용 단가(로스 반영) 2값 노출(`@sikjae/core` 계산).

## 6. 고정 지출 (MY-02)

- 자세히 보기(읽기) + 수정(편집) 2화면. 편집은 **항목 행/카드 동적 추가·삭제**, 금액 입력칸 '원' 접미사 제거, 카드 제목-항목 사이 구분선.
- 레시피 상세/추가에서 고정 지출 카드 → **자세히 보기**로 진입(`/recipes/fixed-cost`).

## 7. 레시피 (RCP)

- 리스트 카드: '재료 원가율' → **재료비** 라벨. 숫자 15 / 퍼센트 13.5. **판매가·재료비=그레이, 순이익=블랙**.
- 추가 화면: 재료 행 = 우측 화살표(›) → **사용량 입력 시트(삭제/담기)**. 추가 지출 = 편집행([지출명][금액][X] + 추가).
- 재료 검색·담기(RCP-09): 식재료 리스트 카드 스타일 + 카드 탭 → 사용량 입력 시트(생산량 기준 / 1개당).
