## 구현 및 현재 판정

`node scripts/ingredient-p3-scope-check.mjs`는 승인 SHA의 조상 관계, 정확한 파일 blob,
기존 기준선 불변, staged/unstaged/untracked 변경을 검사한다. 승인 경로 안이어도 새 내용은
자동 승계되지 않는다. 다른 도메인·공용 코드·경로 탈출·가짜 glob은 허용하지 않는다.
Expo의 `[id].tsx`는 glob으로 확장하지 않고 정확한 파일명으로만 비교한다.

- 순수 분류기 시험: 39/39 PASS.
- 승인 SHA에서 식재료 변경 33개 허용, 범위 밖 제품 변경 83개 차단, 형식 오류 0개.
- 83개는 이번 결정의 범위 밖이라는 뜻이며, 83개 기능 결함 판정이 아니다.
- 현재 명령은 **승계 전처리 검사**다. 기존 `three-surface-p0-check.mjs`, baseline,
  `verify`의 필수 게이트를 교체하거나 우회하지 않는다. P3 전체 활성화 완료가 아니다.
- 다른 도메인과 공용 코드의 검토·권한 판정, 기존 게이트 스크립트 hash 결속의 정식 승계,
  S3A/S4/touch/visual/native 증거 재검증, 문서 그래프·byte artifact 정합성이 남는다.
