## Claude R6 대조

R6 원본은 보존한다. 새 P1/P2 없음이며 다음 범위를 직접 판단했다.

- R6-1: 입고 이력의 전후값은 화면에 보이던 **현재 메뉴 기준단가**에서 새 평균으로 바뀌는 값이다. 평균끼리의 변화로 되돌리면 직접10→평균8 전환이 이력에서 사라지므로 현재 비교를 유지한다. 급등도 현재 기준단가 대비다. 실제 입고 평균 원문은 원장 함수와 입고 내역으로 유지된다.
- R6-2: 입고를 모두 취소하면 평균은 null이다. 과거 구매 가격을 자동 부활시키지 않는다. 명시적 구매 가격 재수정으로 새 직접 기준을 만들 수 있다. tests/73에서 null과 0을 구분했다.
- R6-3: 기존 행에 임의 backfill하지 않는다. 현재 단가 출처의 별도 UI 표시는 후속 UX 사항이며 이번에 추가하지 않았다. 사용자에게 새 저장·입고부터 적용된다는 범위를 알렸다.
- R6-4/5/6: 미세 반올림 경계, 마감 추이 원인의 식재료명 누락, 추이 차트 수동/입고 출처 표시는 남은 검수 항목이다. 이 수정으로 해결됐다고 표현하지 않는다.
- R6-7: 앱 expected는 명시한 편집 필드만 보내며 새 override 컬럼을 포함하지 않는다. 기존 편집 충돌 시험과 관련 앱 시험을 통과했다.
