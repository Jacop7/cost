## 이번 변경

1. 메모는 `save_ingredient`의 `patch=memo` 경로로 ID·메모·최초 메모만 보낸다. 서버는 권한 검사와 행 잠금 후 메모만 비교·갱신한다. 동일값 재시도는 no-op, 충돌은40001. 원장·수정내역 제외 정책 유지.
2. 전체 수정 폼은 최초 조회 필드의 `expected`를 보존한다. 서버는 행 잠금 뒤 값이 달라졌으면40001로 거절한다. 배경 재조회가 확인 기준을 바꾸지 않는다.
3. 차감/폐기 성공 응답 유실 뒤 잔량이 부족하거나0이어도 동일 요청키와 최초 확인 재고로 재시도할 수 있다. 입력 변경과40001은 새 재고로 검증한다.
4. 실제 알림 여부와 무관했던 메인 알림 점을 제거하고 목적지 이름을 ‘알림 설정’으로 맞췄다.
5. AppMap의 구매처 선택/식재료 삭제 옛 문구 검사를 실제 화면과 일치시켰다.
6. 숨김 폐기내역 URL은 재고내역으로 이동한다. 과거 손실을 현재 단가로 산출하던 화면과 구형 취소 입구를 제거했다. 기존 DB RPC나 원장 기록을 지운 것은 아니다.
