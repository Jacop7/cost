# 마스터 중심 심플 플러그인 — 범위·기록 구성 정정 002

작성일: 2026-09-09. 상태: 방향 검토 후보, Claude 앱 자문 요청 중.

## 1. 이번 범위

사용자의 후속 설명에 따라 [기획안 001](./MASTER-CENTERED-SIMPLE-PLAN-001.md)과 [실행계획 001](./MASTER-CENTERED-SIMPLE-EXECUTION-001.md)의 상시 자동화에 준하는 구현 범위·10~15일 추정을 이번 MVP 범위에서 제외한다. 기존 도구로 채팅을 조회·지시·확인하는 마스터용 플러그인과 역할·업무 기록이 구현 대상이다. 원래 초안은 변경 이력으로 보존한다.

마스터가 실행 중일 때 조율한다. 세션이 종료돼도 스스로 계속 실행되는 서비스·예약은 포함하지 않는다. 14개 논리 역할을 기존 채팅에 연결하는 후보를 준비하며 실제 채팅 생성·이관은 별도 요청 범위다. P4/P6나 Directory Discovery의 승인·완료를 이 MVP로 대신하지 않는다.

## 2. 원본과 역할별 보기

| 자료 | 원본 소유 | 역할별 파일 |
|---|---|---|
| 현재 작업 상태 | 기존 통합 작업큐, 마스터 갱신 | 별도 상태 복사 금지. Task 링크로 조회 |
| 업무 지시·결과·검수 | Task별 단일 원본. 기존 검수 장부 경로 재사용 | 업무이력.md는 Task ID·한 줄 요약·링크만 |
| 검증된 교훈 | 기존 TEAM_LEARNING.md | 교훈.md는 역할에 해당하는 learning_id·링크를 보여주는 색인 |
| 역할 수행 규칙 | 역할별 지침.md | 적용 규칙·공식 정책·검증된 교훈 ID 연결 |
| 스터디 | 역할별 스터디.md | 원본 문서·읽을 구간·업무별 추가 자료 |
| 실제 채팅 연결 | 비공개 로컬 매핑 | 공식 문서에는 role_id만. 실제 endpoint ID는 공식 Git 문서에 저장하지 않음 |

기존 [TEAM_LEARNING.md](../../team/TEAM_LEARNING.md)는 CANDIDATE → VERIFIED → RETIRED 상태·적용 조건·출처·검증 근거·만료·충돌을 이미 갖춘다. 별도 역할별 교훈 원장을 만들지 않는다. 역할 지침에 규칙을 반영해도 교훈의 검증 상태와 정책 권위는 이 장부 및 공식 정책을 따른다.

업무이력·교훈 색인은 원본에서 다시 만들 수 있어야 한다. 색인 생성 시 원본 판본을 적고, 최신성 불명 시 원본을 조회한다. 역할별 색인이 Task 상태나 교훈 VERIFIED 판정을 덮어쓰지 않는다.

## 3. 작성자와 학습 흐름

- 수행자: Task 결과와 근거, 교훈 후보 제출.
- Quality/해당 검수자: 재현·반례·적용 범위 검증. 개발자의 설명만으로 VERIFIED 판정하지 않음.
- 마스터: Task 상태·담당·순서 갱신, 검증된 결과의 합류 조율.
- Knowledge: 교훈 장부의 정해진 절차 및 역할 색인·지침 반영 관리.
- 사람: 정책·권한·운영 위험 결정을 담당. 단순 기록 정리까지 반복 승인받지 않음.

업무 시작 시 VERIFIED 중 관련 조건에 맞고 유효기간 내이며 충돌하지 않는 교훈만 선택한다. 독립 종합 감사와 최초 보안 감사에는 기존 정책대로 학습 컨텍스트를 주입하지 않는다.

업무 종료 시 원인·해결·시험·재사용 범위·반례를 추출해 후보로 제출한다. 검증된 항목만 재사용한다. 정책 변경이 필요한 교훈은 해당 정책 검수·결정 후 반영한다. 폐기된 교훈이 지침에 남으면 참조 관계로 찾아 수정 대상으로 표시한다.

## 4. 최소 기능 및 확인

1. role_id로 담당 채팅 조회. 다른 대상이면 전송하지 않음.
2. Task ID·판본·담당·수정 경로를 포함해 지시. 수신이 불명확하면 재조회.
3. 실제 결과와 검수 원본을 확인한 뒤 상태 갱신. 중복 실행과 과거 판본 결과를 구분.
4. 동일 파일 변경은 하나의 통합 담당 또는 직렬 순서로 배정.
5. 채팅 교체 시 role_id·지침·Task 상태를 복원하고 옛 채팅과 이중 실행하지 않음.
6. 검수는 S0/S1 자체·마스터, S2/S3 Fable/Opus 포함. 작은 문서라도 정책·권한을 바꾸면 상향.
7. 현재 작업·업무 원본·검증된 교훈·역할 지침의 책임과 연결 검사.

## 5. 기간과 현재 검수 범위

초안 약 1작업일, 기존 도구 연결 시범·검수 수정 포함 2~3작업일은 제한된 MVP의 조건부 추정이다. 외부 회신 대기, 기존 정책 합류, 도구 이용 불가, 다수 기존 업무 이관은 제외한다. 실제 연결 확인 전에는 확정 납기나 구현 완료를 주장하지 않는다.

사용자가 지정한 Claude 앱 'AI 팀 지식망 스터디·인계' 채팅에 방향 자문을 요청했다. 요청은 기존 연결을 담당한 Codex 작업을 통해 전달·회수하도록 했다. 전달 완료와 Claude 결과 수신은 실제 응답으로 별도 확인한다. 이 자문은 공식 CLI 독립검수 영수증이나 구현·배포 승인으로 기록하지 않는다.
