## 철회 사유

**1. 이미 있는 것을 새로 제안했다.**
기본 → 의미 → 컴포넌트 3계층은 실행서 §3(`C-01`~`C-21`, §3.1~3.9 확정 값 표)과
UI 가이드 §1~5에 이미 확정돼 있다. 이 문서는 그 자리를 읽지 않고 새 구조를 제안해
두 번째 경쟁 표준을 만들 뻔했다. `AGENTS.md`의 단일 정본 원칙에 어긋난다.

또한 "색 정본을 어디로 둘 것인가"를 열린 결정으로 남겼으나, UI 가이드 §1.2가
"이 문서가 임의 색을 확정하지 않는다. 대비 검산 후 `tokens.ts`에 추가한다"로
**이미 답을 정해 두고 있었다.** 답이 있는 질문을 다시 물었다.

**2. 수치가 재현되지 않았다.**
앱 실측을 임시 grep으로 냈고 세는 규칙을 적지도 스크립트로 남기지도 않았다.
