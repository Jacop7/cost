# Git 이력 재작성 SHA 대응표

- 확인일: 2026-09-14
- 목적: 작성자 이메일 정정으로 다시 만들어진 커밋을 현재 검증 봉인에 연결
- 판정: 각 쌍은 커밋 제목과 tree SHA가 같고, 새 SHA는 현재 HEAD의 조상이다.

이 대응표는 이전 커밋이나 검수 영수증을 수정하지 않는다. 현재 실행 게이트의 참조만 동일 tree를 가진
현재 이력의 커밋으로 전진한다. 숨은 `git replace`나 graft는 사용하지 않았다.
