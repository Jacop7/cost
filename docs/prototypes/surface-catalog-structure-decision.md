# 실제 Expo /appmap 개발 탐색기 구조

2026-09-09 사용자 요청: 기존 Expo를 유지하고 프로토타입과 같은 순서의 탭에서 **같은 실제 Expo**를 연다.
현재 디자인을 다시 구현하거나 프로토타입 HTML로 대체하지 않는다. 정식 P4 전체 종결 선언과 구분한다.

선택은 앱 외부의 로컬 탐색기(`scripts/appmap`) + 기존 Expo 경로 iframe이다.

- production 제외: 앱 route/bundle에서 탐색기를 import하지 않는다. loopback 개발 서버만 제공한다.
- provider 동일성: iframe은 기존 Expo router 진입점을 그대로 열어 Session/Query/SafeArea/폰트 공급자를 공유한다.
  공급자나 제품 JSX를 탐색기에서 다시 구현하지 않는다.
- 설정 변경: Expo Metro 8094 앞에 로컬 8091 프록시를 둔다. `/` 등 기존 경로는 그대로 통과한다.
  제품 설정·토큰·DB·네이티브 진입점·기존 `.env`는 변경하지 않는다.
- 앱 route에 카탈로그를 추가하는 안은 제품 번들/레이아웃에 침투하므로 이번 최소 연결 요청에서는 선택하지 않는다.
- 프로토타입의 순서/이름 리터럴만 읽는다. 185 target 집합과 감사 원본을 대조하며 숨김 3개를 목록에서 보존한다.
- 실제 ID는 실제 Expo 목록 응답의 id/name을 관찰해 선택한다. 초기에는 목록의 첫 실제 항목을 사용하며 선택기로 바꿀 수 있다.
- popup은 기존 열기 동작만 연결한다. 자동 저장/삭제/확정 없음. 미연결은 host-only 경고이며 동일 상태로 판정하지 않는다.
- 개발자 코드 수정은 한 Expo 소스에만 적용된다. 양쪽의 독립 입력 중 임시 폼 값은 서로 자동 복사하지 않는다.
  사용자가 저장한 데이터는 같은 로컬 DB를 사용한다.

이 문서는 탐색기 구조 기록이다. 디자인 일치, 모든 popup 직통, native 3면 격리 및 정식 P4 완료를 승인한 문서가 아니다.
