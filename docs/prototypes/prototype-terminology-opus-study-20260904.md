### 6.5 제1차 보고서의 유실 규칙과 겹치는 부분

- `매출 계산과 무관` — "판매·손익 계산에 영향 없음"
- `폐기 손실` — "실제 폐기가 손익에 반영된 금액. **추정 로스율과 구분**"

### 7.5 UI 버그 2건

- **화면 링크 없음**: 카드는 `<small class="term-scope">적용: ${scope}</small>` 평문만 렌더한다. `scope`의 `ING-06`·`SALES-10`이 `screens[*].route`와 같은 표기인데도 **클릭해 해당 화면으로 갈 수 없다.** 사전↔화면 왕복이 끊겨 있는 것이 UI상 가장 큰 미완성이다.
- 부수: 요약 타일이 `검수 범위 62 + 125`라고 표시하는데, **125는 팝업 호스트 수가 아니라 팝업 엔트리 수**다(호스트는 35~49). 제1차 보고서 F-2의 수치 혼선과 같은 뿌리.
